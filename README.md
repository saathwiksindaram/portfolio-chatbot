# Saathwik's Portfolio

Hi! I'm Saathwik, a B.Tech Artificial Intelligence and Machine Learning student at VNR Vignana Jyothi Institute of Engineering and Technology.

I created this portfolio to showcase my projects, technical skills, achievements, and coding profiles in one place. I also added an AI chatbot that can answer questions about my profile and projects.

## What this project does

This is more than just a basic portfolio website. It combines a personal portfolio with an AI-powered chatbot.

Visitors can:

- Learn about me and my interests
- Check my technical skills
- Explore my projects
- View my achievements
- Access my resume
- Visit my coding profiles
- Ask the chatbot questions about my background and work

## AI Chatbot

The main feature of this project is the portfolio chatbot.

Instead of searching through different sections of the website, visitors can simply ask questions such as:

- What are Saathwik's technical skills?
- Tell me about his projects.
- What is PrintAI?
- What machine learning projects has he worked on?
- What are his achievements?
- Where can I find his coding profiles?

The chatbot uses the Google Gemini API and is given information about my profile so that it can provide relevant answers.

## Projects Included

### Resume Skill Gap Analyzer

A web-based project that analyzes resumes and identifies possible skill gaps using a resume dataset and XGBoost.

### PrintAI - Smart Printing Assistance System

A smart printing idea designed to reduce waiting time and crowding at stationery shops. Students can submit their printing requirements in advance so that the documents can be prepared before they arrive.

### Water Turbidity Prediction

A machine learning project that uses historical water-quality and time-series data to predict water turbidity.
